# Esperimenti con modelli classici

Questa cartella contiene gli artefatti prodotti dalla pipeline scikit-learn
BUILD_1. Il codice corrispondente è in
`../../../ML_pipeline/classical_ml_preprocessing/`.

- `arrays/`: matrici sparse CSR e label per gli split;
- `artifacts/`: OneHotEncoder, StandardScaler e metadati delle feature;
- `models/`: modelli addestrati serializzati con joblib;
- `reports/`: Recall@6, tempi, baseline e training summary.
