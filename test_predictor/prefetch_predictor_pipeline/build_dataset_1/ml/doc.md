# Artefatti ML BUILD_1

Questa cartella raccoglie gli output del preprocessing e degli esperimenti ML
eseguiti sul dataset BUILD_1. Non contiene codice: gli script riutilizzabili
vivono in `../../ML_pipeline/`.

- `training/`: Parquet, split per prompt e array numerici prodotti dal
  preprocessing base;
- `classical_ml/`: matrici sparse, encoder/scaler, modelli e report dei
  classificatori scikit-learn.
